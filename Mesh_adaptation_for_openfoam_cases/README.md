# Mesh Adaptation for OpenFOAM Cases — Mach 3 Cylinder

This is the OpenFOAM Mach 3 cylinder case. It refines the mesh using
the **pressure gradient** `|grad(p)|` as the criterion and is built and
run exactly like `rhoCentralFoam` cases are: a Gmsh mesh is converted
with `gmshToFoam`, the solver runs, and the result drives the next AMR
mesh.

The case supports two workflows:

- **Mesh-only demo** (no solver) — produce the AMR mesh from a bundled
  result. Needs only Gmsh (and ParaView if you regenerate the field).
- **Full pipeline** (solver in the loop) — run `rhoCentralFoam` for the
  configured number of AMR loops. Needs OpenFOAM v2406.

The free-stream is the converged solution of `rhoCentralFoam` on a 2D
cylinder at 50 km altitude (`U_inf = 990 m/s`, `T_inf = 270.65 K`,
`p_inf = 79.78 Pa`, isothermal wall at 800 K).

## Files in This Folder

| File | What it is |
|------|------------|
| `amr_pipeline.input` | **The one file you edit.** Holds the binary paths, the geometry/mesh names, the gradient field (`p`) and sizing parameters, and the OpenFOAM solver settings (`foam_source`, `solver`, `case_dir`, `boundary_fix`). |
| `mach3_cylinder.geo` | Baseline geometry — rectangular domain with a cylinder, extruded one cell in z so OpenFOAM treats it as 2D. Tags the `inlet`, `outlet`, `wall`, and `frontAndBack` patches. |
| `mach3_cylinder_amr.geo` | Same geometry plus the lines that load `mfp.pos` as a Gmsh `Background Field`. |
| `mach3_cylinder.msh` | Uniform mesh used as the starting point. |
| `mach3_cylinder_amr.msh` | The AMR-refined mesh — the end product of the mesh-only demo. |
| `mfp.pos` | Bundled sizing field (Gmsh PostView). `mach3_cylinder_amr.geo` loads it as a `Background Field`, so the AMR mesh can be built with Gmsh alone. Also regenerated by `generate_amr_mesh.sh`. |
| `generate_amr_mesh.sh` | The mesh-only driver. Reads every value from `amr_pipeline.input`, runs `final.py` in gradient mode, then runs Gmsh and writes the AMR mesh. No solver involved. |
| `openfoam_case/` | The OpenFOAM case directory. `0.orig/` holds the initial/boundary fields, `constant/` the thermophysical and turbulence models, `system/` the `controlDict`/`fvSchemes`/`fvSolution`. `gmshToFoam` fills in `constant/polyMesh` at run time. |
| `precomputed_result/field/auto_field.pvd` | ParaView collection that the demo's `final.py` invocation reads. |
| `precomputed_result/field/step_5_m1_g1/field_g0_m0.vtu` | The bundled converged `rhoCentralFoam` field. |

The full-pipeline scripts (`run_openfoam.sh`, `run_openfoam_amr.sh`,
`all_run.sh`, `final.py`) live in [`../master_script/`](../master_script/)
and are shared by every case; `amr_pipeline.input` points at them.

## Quick Path — Gmsh Only (no ParaView, no OpenFOAM)

Because the sizing field `mfp.pos` is bundled in this folder, you can
build the AMR mesh directly with Gmsh — nothing else is needed:

```bash
gmsh mach3_cylinder_amr.geo -3 -o mach3_cylinder_amr.msh
```

`mach3_cylinder_amr.geo` merges `mfp.pos`, sets it as the background
field, meshes the 2D section, and extrudes one cell in z so the result
is an OpenFOAM-ready (`.msh` v2.2) mesh.

## Mesh-Only Demo (regenerate the field, then mesh)

To regenerate `mfp.pos` from the bundled result and then mesh:

```bash
# Edit amr_pipeline.input — set gmsh_bin and pvpython to your absolute paths
./generate_amr_mesh.sh
```

After it finishes you will have `mfp.pos`, `filtered_mfp.csv`,
`all_data.csv`, and `mach3_cylinder_amr.msh`. Open the two meshes side
by side to see the refinement:

```bash
gmsh mach3_cylinder.msh        # uniform starting mesh
gmsh mach3_cylinder_amr.msh    # AMR mesh
```

The AMR mesh has small cells along the bow shock and in the wake behind
the cylinder, where `|grad(p)|` is large, and stays coarse in the
smooth free-stream and far-wake regions.

## Full Pipeline (OpenFOAM in the loop)

With OpenFOAM v2406 installed, run the complete AMR pipeline — uniform
mesh → `rhoCentralFoam` → extract `|grad(p)|` → AMR mesh → run again,
for `loops` iterations:

```bash
# Edit amr_pipeline.input: gmsh_bin, pvpython, foam_source
../master_script/all_run.sh
```

`all_run.sh` calls `run_openfoam.sh` for the uniform mesh and
`run_openfoam_amr.sh` for each AMR mesh. Both wrappers convert the Gmsh
mesh with `gmshToFoam`, fix the boundary patch types from
`boundary_fix`, run `rhoCentralFoam`, and export VTK for the next
extraction step. To run a single AMR-mesh solve directly:

```bash
../master_script/run_openfoam_amr.sh
```

## Sizing Formula Used

```
h(x) = h_min + (h_max − h_min) / (1 + α · |grad p(x)| / max |grad p|)
```

with `h_min = 0.002 m`, `h_max = 0.015 m`, `α = 100`, set in
`amr_pipeline.input` as `sizing_min`, `sizing_max`, and `sizing_scale`.
Increase `α` for sharper refinement, decrease it for softer.
